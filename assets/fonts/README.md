# Bundled fonts

Workamon bundles the Latin WOFF2 subsets so the UI does not depend on a
third-party font CDN.

- **Manrope** — body/UI text. SIL Open Font License 1.1.
- **Space Grotesk** — headings, brand, and prominent metrics. SIL Open Font
  License 1.1.
- **JetBrains Mono** — technical values, logs, and code. SIL Open Font License
  1.1.

The files were downloaded from Google Fonts. The corresponding license texts
are included as `OFL-Manrope.txt`, `OFL-SpaceGrotesk.txt`, and
`OFL-JetBrainsMono.txt`.
